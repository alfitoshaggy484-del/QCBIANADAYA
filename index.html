🚀 Panduan Setup Firebase (5 menit)

Ikuti langkah berikut untuk menghubungkan database cloud gratis ke aplikasi ini.

① Buat Project Firebase
  1. Buka console.firebase.google.com → klik Add Project
  2. Beri nama project (misal: qualityform-bdf)
  3. Ikuti wizard sampai selesai
② Aktifkan Authentication
  1. Di sidebar Firebase → Authentication → Get started
  2. Pilih provider Email/Password → Enable → Save
③ Buat Firestore Database
  1. Di sidebar → Firestore Database → Create database
  2. Pilih Start in test mode (bisa diubah nanti)
  3. Pilih region terdekat (misal: asia-southeast1 untuk Jakarta)
④ Salin Konfigurasi ke File ini
  1. Di Firebase Console → klik ikon ⚙️ → Project settings
  2. Scroll ke bawah → Your apps → klik </> Web
  3. Daftarkan app → salin objek firebaseConfig
  4. Buka file index.html ini → cari bagian GANTI_API_KEY_ANDA → ganti dengan nilai asli
⑤ Set Aturan Keamanan Firestore

Di Firestore → Rules → paste aturan berikut:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Rules ini mengizinkan semua akun yang login untuk melihat dan menyimpan data bersama (sinkron antar akun).

✅ Setelah selesai:

Simpan file → buka di browser → akan muncul halaman Login. Karyawan bisa daftar akun sendiri atau Anda tambahkan dari Firebase Console → Authentication → Users.
